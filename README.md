# 🚀 Expotech

Projeto de website desenvolvido para apresentar informações sobre a **Expotech**, um evento voltado à tecnologia, inovação e compartilhamento de conhecimento.

A aplicação apresenta uma interface moderna e organizada para divulgar conteúdos, atividades e informações relacionadas ao evento.

---

## 📌 Sobre o Projeto

A **Expotech** é um evento focado em tecnologia e inovação que reúne estudantes, profissionais e empresas para compartilhar conhecimento por meio de palestras, demonstrações tecnológicas e networking. :contentReference[oaicite:0]{index=0}  

Este projeto tem como objetivo criar uma **plataforma web para divulgação do evento**, oferecendo uma experiência visual agradável e acessível para os usuários.

---

## ✨ Funcionalidades

O site apresenta:

- 🏠 Página inicial com apresentação do evento
- 📅 Informações sobre a programação
- 💡 Destaques de tecnologia e inovação
- 🧭 Navegação simples e intuitiva
- 📱 Layout responsivo para diferentes dispositivos

---

## 🛠 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias de **desenvolvimento web front-end**:

- **HTML5** → Estrutura da aplicação
- **CSS3** → Estilização e layout
- **JavaScript** → Interatividade da interface

---

## 📂 Descrição dos Arquivos

- **index.html** → Estrutura principal da página  
- **style.css** → Arquivo responsável pelos estilos e layout  
- **script.js** → Funcionalidades e interações do site  
- **assets/** → Imagens, ícones ou outros arquivos utilizados no projeto
